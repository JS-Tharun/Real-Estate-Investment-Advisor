Code Description for 3_Investment_Advisor🧠.py

This file is a Streamlit application for a Property Investment Advisor. It loads machine learning models from MLflow and provides a user interface to input property details and get investment recommendations.

Section 1: Imports and Setup
Imports necessary libraries including mlflow, streamlit, pandas, dagshub, os, json, numpy, and dotenv. Sets up the Streamlit page configuration with title "Investment Advisor" and wide layout.

Section 2: Load Dataset
Loads the property investment dataset from "../Datasets/Property_Investment.csv" into a pandas DataFrame called 'dataframe'.

Section 3: Initialize DagsHub and MLflow
Initializes DagsHub connection for the repository 'Real-Estate-Investment-Advisor' with MLflow tracking enabled. Loads environment variables from .env file and sets MLflow tracking credentials and experiment name.

Section 4: Load Champion Models
Defines a cached function 'load_champion_model' that loads three production models ("XGB_Inv_Advisor", "RF_Inv_Advisor", "DT_Inv_Advisor") from MLflow model registry at the 'champion' stage. Uses st.spinner to show loading message while loading the models.

Section 5: Streamlit App UI - Title
Creates a container with the app title "Property Investment Advisor" and a markdown description prompting the user to enter property details.

Section 6: Investment Advisor Form - Location Details
Within a form, creates a card-like container for location details with three columns: City (selectbox from unique sorted city values), Locality (selectbox from unique localities), Direction Facing (selectbox from unique directions).

Section 7: Property Details
Another card container for property details with columns: Property Type (selectbox), Furnished Status (selectbox), Price (slider in lakhs), Size (number input in sqft), BHK (number input), Age of Property (number input in years).

Section 8: Amenities
Card container for amenities with toggles for: Parking Space, Security, Clubhouse, Gardens, Gym, Play Area, Swimming Pool. Converts toggles to 0/1 values.

Section 9: Nearby Facilities
Card container for nearby facilities with inputs: Total Schools Nearby (number), Total Hospitals Nearby (number), Public Transport Accessibility (selectbox).

Section 10: Submit Button
Centers a submit button labeled "💡 Invest?" within the form.

Section 11: Prediction Logic
When submit button is pressed, creates a DataFrame 'X' with the input values. Predicts using each loaded model, takes the mean prediction (majority voting), and displays "Good Investment" or "Bad Investment" based on the rounded result.
