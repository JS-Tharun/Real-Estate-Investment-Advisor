Code Description for 2_Future_Price_Predictor📈.py

This file is a Streamlit application for Future Property Price Prediction. It loads regression models from MLflow to predict future property prices based on user inputs, including confidence intervals and feature importance display.

Section 1: Imports and Setup
Imports necessary libraries including mlflow, streamlit, pandas, dagshub, os, json, numpy, and dotenv. Sets up the Streamlit page configuration with title "Future Property Price Prediction" and wide layout.

Section 2: Load Dataset
Loads the future price dataset from "../Datasets/Future_Price.csv" into a pandas DataFrame called 'dataframe'.

Section 3: Initialize DagsHub and MLflow
Initializes DagsHub connection for the repository 'Real-Estate-Investment-Advisor' with MLflow tracking enabled. Loads environment variables and sets MLflow tracking credentials, experiment name for regression, and tracking URI.

Section 4: Load Champion Models
Defines a cached function 'load_champion_model' that loads three production regression models ("XGBoost_Price_Pred", "RF_Price_Pred_Prod", "DT_Price_Pred_Prod") from MLflow model registry at the 'champion' stage. Uses st.spinner to show loading message while loading the models.

Section 5: Streamlit App UI - Title
Creates a container with the app title "🔮 Future Property Price Predictor" and a markdown description prompting the user to enter property details for prediction.

Section 6: Price Prediction Form - Location Details
Within a form, creates a card-like container for location details with two columns: City (selectbox from unique sorted city values), Locality (selectbox from unique localities).

Section 7: Property Details
Another card container for property details with multiple columns: Property Type (selectbox), BHK (number input), Size (number input in sqft), Price per sqft (number input in lakhs), Furnished Status (selectbox), Direction Facing (selectbox), Floor Number (number input), Total Floors (number input), Age of Property (number input in years), Owner Type (selectbox), Availability Status (selectbox).

Section 8: Amenities
Card container for amenities with toggles for: Parking Space, Security, Clubhouse, Gardens, Gym, Play Area, Swimming Pool. Converts toggles to 0/1 values.

Section 9: Nearby Facilities
Card container for nearby facilities with inputs: Total Schools Nearby (number), Total Hospitals Nearby (number), Public Transport Accessibility (selectbox).

Section 10: Submit Button
Centers a submit button labeled "🔮 Predict Future Price" within the form.

Section 11: Prediction Logic
When submit button is pressed, creates a DataFrame 'X' with the input values. Predicts using each loaded model, calculates mean prediction, standard deviation, confidence level, and price interval (mean ± 2*std). Displays predicted price, confidence tier and percentage, and expected price range.

Section 12: Display Feature Importance
Loads feature importance data from 'data/reg_feature_score.json', converts to DataFrame, and displays it in a container with a dataframe showing feature rankings.
